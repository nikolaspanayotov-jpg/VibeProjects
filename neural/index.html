A useful way to learn.

Our rule: the lamp should be on when exactly one switch is on. Off / On → Yes. On / On → No. This rule is called XOR.

What do the numbers mean?

0 means off or no. 1 means on or yes. We know the rule, but the network is only given four example answers. Its connections start with random settings.

A neural network is a group of small calculations connected together. Give it examples, and it can adjust those connections to get better at producing answers.

The words, in everyday language

You do not need to memorize these. They connect the explanations above to the names you may see elsewhere.

Neural network / neuron
A network connects small calculators called neurons. Each uses incoming numbers to make an outgoing number. It is a mathematical model, inspired by some ideas from brains.
Input, output, hidden layer
Inputs are the numbers you give it. The output is its answer score. The hidden layer is the group of calculators in between; “hidden” just means they are neither the supplied inputs nor the final output.
Weight
A connection’s influence. An incoming number is multiplied by this setting. A positive weight pushes the next total up; a negative one pulls it down. Learning adjusts these settings.
Bias
A learned starting nudge added inside a calculator. It shifts the total even when the inputs are zero, helping the network fit a pattern.
Activation / sigmoid
Activation is a calculator’s outgoing signal. This demo uses a function called sigmoid to squeeze a total into a value between 0 and 1. That extra step lets layers combine into more flexible patterns.
Training / epoch
Training is practice: compare guesses with correct answers, then adjust the settings to reduce mistakes. One epoch means one pass through all the examples, called a practice round here.
Loss / mean squared error (MSE)
One measure of how far the guesses are from the correct answers. We square each difference, then average all four. Lower is better. A guess of 0.8 with a target of 1 contributes (0.8 − 1)² = 0.04.
Gradient descent / backpropagation
Backpropagation calculates how changes to each setting would affect the error. Gradient descent uses those calculations to make small adjustments in a direction that reduces the error.
Classification / accuracy
Classification turns a score into a category: No below 0.5, Yes at or above it. Accuracy counts how many categories match the correct answers. Error also measures how close the scores are, so it can improve even when the count stays the same.

Questions you might have

Why not just tell it the rule?

We could write an ordinary rule to solve this switch problem instantly. We use examples here to show a different approach: learning settings from answers. That approach becomes useful when describing the full rule by hand is difficult, such as recognizing patterns in images.

Why is “exactly one on” harder than “both on”?

For “both on,” only one of the four input pairs needs a Yes. For “exactly one on,” the two Yes pairs lie at opposite corners of the map. One straight dividing line cannot separate those Yes answers from the No answers. The middle calculators allow a more flexible division, but learning it can take longer.

Why do my results differ after Reset?

The connections start at random settings so the middle calculators can learn different roles. Different starts can improve at different speeds, and a run can get stuck. Try more rounds or Reset if progress stalls. The walkthrough describes what to look for, not a guaranteed number of rounds.

Does changing a slider teach it? Does a bright circle mean it knows more?

No. Input sliders only change the question it answers using its current settings. Learning changes the settings. A brighter circle means its outgoing number is larger for this question, not that it has learned more or is more certain.

What does “learned” mean in this demo?

The demo pauses when every practice score is within 0.08 of its correct answer: below 0.08 for No, or above 0.92 for Yes. This only measures the four examples it practiced. Testing performance on separate, unseen examples is important in real machine learning; this tiny demo does not do that.
